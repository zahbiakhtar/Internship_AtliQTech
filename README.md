## 📅 **Week 1 – HR Analytics & Data Preparation**

### 🔹 Task 1: Data Cleaning

**Dataset:** `attendance_data.csv`
**Objective:** Prepare raw HR attendance data for analysis.

**Key Cleaning Steps:**

* Standardized date format to `YYYY-MM-DD`
* Extracted **Month Name** and **Day Type**
* Cleaned Employee IDs (removed special characters like `@`)
* Converted employee names to **Title Case**
* Mapped status values to abbreviations:

  * WFO, WFH, BL, ML, PL, SL, WO
* Removed duplicate records
